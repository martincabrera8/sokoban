# Carpeta temporal

Material para compartir dentro del equipo. No es parte de la entrega: se borra antes de mostrar el repositorio.

- `presentacion/dist/presentacion-sokoban.html`: la presentación lista. Abrir con Chrome o Edge y apretar F11. Se avanza con las flechas; arrastrando con el mouse se giran las escenas 3D; N abre las notas del expositor. Incluye el dominio (Pedro y Lucía) y el sonido (Mora).
- `presentacion/`: las fuentes de la presentación, para editarla (ver `presentacion/README.md`).
- `docs/uml/`: diagramas UML (completo, por patrón: Observer, Facade, Singleton, Strategy, Mediator, Decorator, State y deshacer, vista general, cómo leer las flechas y secuencia).
- `docs/guia/Guia-del-proyecto-Sokoban.pdf`: guía que explica cada clase y cada patrón, con listas de chequeo.
- `docs/integracion.md`, `docs/interfaz.md`: documentación de la integración y de la interfaz.
